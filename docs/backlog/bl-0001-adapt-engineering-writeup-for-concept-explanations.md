# engineering-writeup 개념 설명 문맥 보강

- **ID:** BL-0001
- **기록일:** 2026-08-15

## 배경

`engineering-writeup` 스킬을 사용해 OAuth `state` 적용 작업을 기술 노트로 정리하는 과정에서, 기본 구조가 구현 완료 보고서나 PR 설명에 가깝게 적용되었다. 그 결과 스킬이 글의 목적과 직접 관련이 약한 `테스트와 검증` 방식까지 새로 구성했고, OAuth, 쿠키, 익명 세션 같은 개념이 처음 등장할 때의 설명도 충분하지 않았다.

작성 의도는 프로젝트 내부 구현 세부만 기록하는 것이 아니라, 이 프로젝트를 모르는 일반 독자도 OAuth `state`와 쿠키 기반 세션의 맥락을 이해할 수 있도록 돕는 것이었다. 그러나 `AuthController`, `external`, `SessionStore` 같은 프로젝트 고유 용어가 이른 시점에 등장하면서 독자가 내부 구조를 알고 있어야 이해하기 쉬운 글이 되었다.

## 목표

`engineering-writeup` 스킬이 문제를 이해하고 해결한 과정과 그 안에서 얻은 배움을 독자 수준에 맞게 남기도록 개선한다. 새로운 용어가 처음 등장할 때 짧고 명확한 설명을 먼저 제공하고, 프로젝트 고유 구현명은 개념을 설명한 뒤에 연결하도록 유도한다.

기본 섹션을 기계적으로 모두 포함하지 않으며, 실제로 수행된 테스트나 검증은 문제 해결의 근거가 될 때만 기록한다. 문서를 위해 새로운 테스트·검증 방법을 만들거나 앞으로 할 일을 체크리스트로 추가하지 않는다. PR·MR 작성과 게시 흐름은 별도 스킬의 책임으로 분리한다.
