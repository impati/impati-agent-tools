# Backlog

지금 구현하지 않지만 나중에 다시 검토할 문제와 작업 후보를 독립 항목으로 기록한다.

- 추적 ID: `BL-NNNN` 형식의 순차 증가 고유 번호
- 파일명: `bl-NNNN-kebab-case-title.md`
- 필수 내용: 제목, ID, 기록일, 배경, 목표
- 제외 내용: 상태, 우선순위, 담당자, 기한

같은 ID를 백로그 파일, `feature/bl-NNNN-title` 브랜치, `<type>(bl-NNNN): <한국어 요약>` 커밋과 코드 리뷰 보고에 사용한다.

항목 추가에는 `capture-backlog` 스킬을 사용한다.
